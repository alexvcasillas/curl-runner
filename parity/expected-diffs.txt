# Allow-list for parity/run.sh. Format: case|flagset|signature|reason
# Exact names only (no globs). flagsets: default, continue-on-error, strict-exit, parallel, dry-run.
# signature = the exact set of differences the cell may have, sorted tokens joined by "+":
#   exit            exit codes differ
#   out:<key>       top-level key of the normalized --output JSON differs
#   stdout          normalized stdout differs (dry-run cells only)
#   snapfiles       __snapshots__ files differ (after masking updatedAt/hash/dates)
#   basefiles       __baselines__ / .bl files differ (after masking capturedAt/hash/timing/dates)
#   noout-ts / noout-rust   no --output file written by that CLI
# A cell with any other difference (or a crash/hang, exit >=124) fails. Every reason
# cites the crates/CHANGES-FROM-TS.md entry that explains it; a reason starting with
# "BUG" would mark a known unfixed bug (none right now).

# --- Dry run with `store`: TS interpolates `${store.x}` to "" and prints `Stored: x = ""`;
# Rust leaves `${store.x}` literal and prints no Stored lines (controller ruling: keep Rust).
# `when` conditions then evaluate differently, hence the skipped/successful diffs in conditional-shorthand.
