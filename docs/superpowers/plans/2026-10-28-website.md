# curl-runner Website + Fumadocs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `packages/docs` with one Next.js app serving the Monochrome marketing site, Fumadocs docs at `/docs` and a generated `/changelog`, on pnpm, with Bun gone from the repo.

**Architecture:** The app stays at `packages/docs` (no Vercel Root Directory or `release.yml` path change). Marketing pages are server components prerendered at build, sharing a small set of Monochrome components; the only client components are the install tabs and copy buttons. Docs move to MDX under `packages/docs/content/docs` via fumadocs-mdx, themed with the same tokens. `/api/test/*`, `install.sh` and `install.ps1` are untouched.

**Tech Stack:** Next.js 16 (App Router), React 19, Tailwind CSS 4, fumadocs-core / fumadocs-ui 16, fumadocs-mdx 15, Geist + Geist Mono (`geist` package, `next/font`), Shiki, Vitest 5 + Testing Library (jsdom), Playwright (verification only), pnpm workspace, Biome.

**Spec:** `docs/superpowers/specs/2026-10-28-website-design.md` (mockups: `docs/superpowers/specs/website-mockups/*.dc.html` — layout, copy and styles; the `.dc.html` wrapper and `{{holes}}` are the mockup format, not code to ship).

## Global Constraints

- Tokens: ground `#0A0A0A`, surface `#0F0F0F`, hover/selected `#171717`/`#1F1F1F`, hairline `#1F1F1F` (inside) / `#262626` (cards, inputs), text `#EDEDED`, secondary `#A1A1A1`, tertiary `#8A8A8A`, accent `#22D3EE`, success `#4ADE80`, error `#F87171` (terminal output only).
- Type: Geist (UI, headings 700 with negative tracking on display sizes) and Geist Mono (code, eyebrows, file names), self-hosted via `next/font`.
- Primary button `#EDEDED` fill / `#0A0A0A` text; secondary 1px `#262626` outline; radius 8–10px buttons, 12–14px cards; content max-width 1200px, 24px gutters.
- Marketing site dark only. No gradient washes, glow, emoji or template look.
- No invented stats, logos or testimonials; competitor cells verified before launch.
- URLs that must keep working: every `/docs/...` page, `/docs/<page>.md`, `/docs.md`, `/install.sh`, `/install.ps1`, `/api/test/...` (incl. `/api/test/delay/[seconds]` taking seconds), `/llms.txt`, `/rss.xml`, `/sitemap.xml`.
- `install.sh` / `install.ps1` byte-for-byte unchanged.
- Public repo: no employer or customer details anywhere (code, docs, commits, PRs).
- Performance: every page prerendered; no client JS on marketing pages beyond install tabs and copy buttons.
- Every code change ships with tests run green (`AGENTS.md`); commits are one-line Conventional Commits.
- Keep Vercel Analytics, Speed Insights and Pulsora analytics.

## Review Focus

1. **Old URLs, exactly as linked today** (trailing slash, `/docs/<page>.md`, `/docs.md`) — each returns 200 with the right content, never a 404. Pinned in Task 15 (`check-site-urls.sh` over the current production sitemap).
2. **GitHub API down or rate-limited at build** — `/downloads` and `/changelog` still build: downloads falls back to a "see GitHub Releases" link, changelog renders without dates. Pinned in Tasks 7 and 9 (fetch mocked to fail).
3. **Changelog entries in every historical shape** (several changesets in one release, Patch + Minor sections together, no bold headline, multi-paragraph bodies) — every `## x.y.z` heading becomes one release, nothing dropped or crashed. Pinned in Task 9 (parse the real `packages/cli/CHANGELOG.md`).
4. **Phone width (390px)** — no horizontal page scroll on any marketing page; code panes and tables scroll inside their own box. Pinned in Task 15 (Playwright).
5. **JavaScript disabled** — the install box shows the default command (`curl -fsSL https://www.curl-runner.com/install.sh | bash`) as selectable text in the server HTML. Pinned in Task 3.
