# curl-runner blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/blog` and `/blog/<slug>` to www.curl-runner.com, and publish the first post, "The importance of testing in the Agent era".

**Architecture:** Posts are a second fumadocs-mdx collection (`content/blog`), read through `lib/blog.ts`. The index copies the changelog page's layout. The post page renders the MDX body with the docs' MDX components. SEO surfaces (sitemap, RSS, OG, JSON-LD, llms.txt, `.md` copies) reuse the existing helpers in `lib/site.ts`, `lib/og-card.tsx`, `lib/page-sources.ts` and `next.config.ts` rewrites.

**Tech Stack:** Next.js 16 app router, fumadocs-mdx 15, Tailwind 4 tokens, vitest + `react-dom/static.node` prerender tests.

**Spec:** `docs/superpowers/specs/2026-10-31-blog-design.md`

## Global Constraints

- All work is in `packages/docs`. Run `pnpm test`, `pnpm typecheck` and `pnpm exec biome check .` (or the repo's lint script) from there.
- Tiptap disclosure: name Tiptap and its document conversion pipeline, link https://tiptap.dev/ and https://tiptap.dev/product/conversion, "hundreds" of smoke tests against preview, staging and production. Nothing internal: no repo names, hosts, CI config, suite names or exact counts.
- The renamed-field scenario is labeled as an example and never presented as a Tiptap incident.
- Author string: `Alex Casillas`. Site URL: `https://www.curl-runner.com`.
- Dark only. Reuse the tokens (`text-fg`, `text-fg-secondary`, `text-fg-tertiary`, `border-hairline`, `border-line`, `bg-hover`, `outline-brand`) and the `FOCUS`/`LINK` class strings from the changelog page.
- `/rss.xml` stays the releases feed. The blog feed is `/blog/rss.xml`.
- No push, PR or deploy until Alex has read the post locally and said so.

## Review Focus

1. A post whose `description` has Markdown or quotes: RSS and JSON-LD must escape it (RSS via `escapeXml`, JSON-LD via `JSON.stringify` with `<` escaped as `<`). Test in Task 3.
2. An unknown slug (`/blog/nope`, `/blog/nope.md`, `/og/blog/nope/image.png`) returns 404 rather than throwing. Test in Tasks 2 and 3.
3. Posts with the same date: the order must be stable (date descending, then title ascending). Test in Task 1.
4. A phone-width reader: code blocks scroll inside their box, never the page. Covered by adding `/blog` and the post to `tests/e2e/phone-width.spec.ts` in Task 2.
5. `/blog/rss.xml` must not collide with `/blog/[slug]`. The static route wins; a test fetches it in Task 3.
