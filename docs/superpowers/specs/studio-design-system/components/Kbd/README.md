# Kbd

A keyboard shortcut hint, set in `code-12`-sized Geist Mono on `surface-300` with `radius-sm`.

- Use macOS glyphs (⌘ ⇧ ⌥ ⌃ ↵) on macOS and `Ctrl+` words on Windows and Linux; the app picks per platform.
- One chord per Kbd. Place it at the end of a button, menu item or palette row, never on its own as instructions.
- Inside a primary button it drops its fill and inherits `on-primary` at 70%.
