# Toggle

Toggles switch a setting that applies immediately; checkboxes pick options that apply when a form is submitted.

- Toggle track 28×16, `radius-full`; on = `primary` track with an `on-primary` knob.
- Checkbox 16×16, `radius-sm`; checked = `primary` fill with an `on-primary` check.
- The label is the whole hit target and states the "on" behaviour ("Stop on first failure").
- GPUI-kit: `Switch`, `Checkbox`.
