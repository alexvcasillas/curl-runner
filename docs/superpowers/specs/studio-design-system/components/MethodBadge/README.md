# MethodBadge

The HTTP method as coloured mono text (`method-10`), fixed 34px wide so names line up in lists.

- Colours: `method-get` blue, `method-post` green, `method-put` amber, `method-patch` purple, `method-delete` red, `method-other` for HEAD and OPTIONS.
- Text only: no fill or border. The word always carries the meaning, the colour only helps scanning.
