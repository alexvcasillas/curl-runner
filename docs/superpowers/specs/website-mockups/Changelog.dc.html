2.0.0 October 28, 2026 Major

Rewritten in Rust, on libcurl

curl-runner 2.0 is a rewrite of the CLI in Rust. YAML files, flags, subcommands, environment variables, config discovery and exit codes stay the same, with the bug fixes and behavior changes below.

MIGRATION · TIMEOUTS ARE NOW MILLISECONDS

1.x passed timeout to curl as seconds. 2.0 honors milliseconds, as documented. Multiply values you wrote for the old behavior by 1000: --timeout 30 becomes --timeout 30000.

Runtime

  • A native Rust binary with libcurl linked statically. No Bun, Node.js or curl binary needed at runtime; HTTPS uses the operating system trust store.
  • curl-runner upgrade replaces the binary in place, checksum verified.

Install changes

  • @curl-runner/cli ships the binary through one optional dependency per platform; no JavaScript, no postinstall.
  • Linux binaries are static musl builds.
  • New: cargo install curl-runner --locked installs from crates.io.

Fixed

  • Transport failures (connection refused, DNS, timeout) now fail the request and are retried; 1.x reported them as success with status 0.
  • Settings resolve as documented: CLI flags beat environment variables, which beat the test file’s global.
  • With several test files, --output now holds the results of all of them, written atomically.
  • Parallel runs keep a sliding window of live requests instead of waiting for the slowest of each chunk.

1.25.0 June 10, 2026 Minor

Security hardening

Secure defaults for curl execution, SSRF and file access, and secret handling — each with an explicit opt-out.

  • Only http and https URLs by default; opt in with --allow-protocol.
  • Output and upload paths are confined to the working directory; opt out with --allow-path.
  • Inline credentials are redacted automatically, including in saved results.
