curl-runner 2.0 — rewritten in Rust on libcurl

API tests as YAML.
Run them anywhere.

Describe requests in plain YAML, validate every response, and run whole suites in parallel — on your laptop or in CI. One native binary, no runtime.

Get started Read the docs
$ {{cmd}}
api.yaml 
global:
  variables:
    BASE: https://api.example.com
  execution: parallel

requests:
  - name: List users
    url: ${BASE}/users
    expect:
      status: 200
      responseTime: "< 500"

  - name: Create user
    url: ${BASE}/users
    method: POST
    body: { name: Ada }
    retry: { count: 3 }
    expect:
      status: 201
terminal
